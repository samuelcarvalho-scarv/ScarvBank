# ScarvBank

## Sobre o projeto

Este é um projeto pessoal desenvolvido com a finalidade de praticar lógica de programação e a linguagem Python.

Embora ainda seja um simulador bancário básico, o ScarvBank representa o início de uma série de projetos que pretendo desenvolver ao longo da minha jornada de aprendizado em tecnologia.

O programa utiliza conceitos como declaração de variáveis, entrada de dados pelo usuário, estruturas condicionais e laços de repetição.

Conforme adquirir novos conhecimentos, pretendo implementar funcionalidades e aprimorar o projeto, registrando minha evolução e meu aprendizado por aqui.

## Funcionalidades

- **Consultar saldo**

  Permite visualizar o saldo disponível na conta. 

- **Realizar saques**

  Permite efetuar saques de valores positivos da conta de acordo com saldo disponível. 

- **Realizar depósitos**

  Permite realizar depósitos, adicionando valores ao saldo disponível na conta.

- **Finalizar atendimento**

  Encerra o programa após ter realizado as operações desejadas. 

## Como executar 

### Pré-requisitos

- Python 3 instalado no computador. 

### Executando o programa

```poweshell
python Scarv_Bank.py
```
